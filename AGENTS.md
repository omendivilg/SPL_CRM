# SPL repository instructions

This Git repository contains SPL Control Financiero.
Follow the global team identities and protocol at `~/.codex/engineering/TEAM.md` and `PROTOCOL.md`.
When working here, read `agents/ARCHITECTURE_CONTEXT.md` and the relevant sections of `agents/OWNERSHIP.md`, `agents/RULES.md`, and `agents/WORKFLOW.md`.
Read only source files and contracts relevant to the task.
For web or mobile visual work, use the local `design-system` skill in `.agents/skills/design-system/SKILL.md`.
For mobile work, also follow `mobile/AGENTS.md`; check the installed Expo major version and matching official documentation before touching Expo APIs.

The global agents are available here, but SPL paths and policies apply only in this repository.
Alley coordinates cross-domain contracts and shared files.
Preserve existing uncommitted work and keep edits focused.
Do not expose secrets, run destructive production data changes, or deploy production without human approval.
